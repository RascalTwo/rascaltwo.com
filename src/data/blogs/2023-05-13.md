# Impactful VSCode Extensions

The most impactful extensions I use in my day-to-day workflow!

Now I'm not going to be pointing out the obvious ones, like "As a P​ython developer, I recommend the [P​ython](https://marketplace.visualstudio.com/items?itemName=ms-python.python) extension", or others that are covered by every other extension-recommendation list, like "Use Prettier to make your code prettier!". If you can find it without scrolling when searching for it in the extensions tab, I'm not going to mention it.

Which leads right into my main piece of advice for finding extensions: simply search for them, no matter how "small" of a technology you're using there's likely a extension or two for it.

Now onto the list, ordered within their individual categories by how impactful they are to my workflow.

- [Generic](#generic)
- [Language-Specific](#language-specific)
  - [Markdown](#markdown)
  - [Web Development](#web-development)
  - [JavaScript](#javascript)
  - [TypeScript](#typescript)
  - [P​ython](#python)

### Python

#### [Wolf](https://marketplace.visualstudio.com/items?itemName=traBpUkciP.wolf)

Adds live inline-feedback to your Python code, showing you the standard output and result of any expression directly in the editor - inspired by the similar extension [Quokka.js](#quokkajs) - making the feedback loop when working with Python that much quicker.

<img src="https://github.com/Duroktar/Wolf/raw/master/images/busy_example.png" alt="screenshot showing print and comment results of a P​ython file" class="ext-img" loading="lazy" />

#### [isort](https://marketplace.visualstudio.com/items?itemName=ms-python.isort)

Automatically sorts imports in Python files, making it easy to keep the imports sorted - and most importantly, your linter happy!

While it aging and may not support all the latest Python features, it's a great learning tool.
